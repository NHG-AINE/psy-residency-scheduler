# Resident request preferences

- Resolve request posting and period against the uploaded catalogue and planning year. Remarks remain recorded without interpretation.
- Match service and, when specified, institution exactly after normalising case and spacing. Unmarked requests are core; (Elective) selects an elective. An optional (Core) suffix is also accepted. Unclear or competing requests remain pending and do not block a draft.
- Blank periods allow any time in the planning year. A wider period permits whole blocks aligned from its start. Only a complete requested block fulfils a request.
- Duplicate rows count once. Maximise each resident's fraction of evaluable requests fulfilled, subject to hard constraints and the shared priority order.
- Draft outcomes describe planned assignments, not completed training credit.
